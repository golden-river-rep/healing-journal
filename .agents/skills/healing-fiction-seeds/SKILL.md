# healing-fiction-seeds

先提炼可复用的情感矛盾、欲望、阻碍、动作和物件。输出素材卡及一个约 500–900 字虚构场景。未提供设定时使用临时人物和第三人称有限视角，标注设定待确认，不声称衔接用户已有小说。通过动作、感官和对话呈现矛盾，避免段末总结人生道理。明确标记新增的角色、对话、场景细节和情节都是虚构；更换可识别人物信息，不照搬私密第三方故事。素材卡列出改编依据、与真实经历的区别、可能接入的剧情位置和未决设定。虚构永不回写 Daily 或事实型文案。使用 templates/creative/fiction.md，输出 fiction-v01.md。

## 输入与证据
读取用户指定的日记或聊天，以及 private/style/ 中对应平台的参考和偏好（若存在）。不扫描其他私人文件。未提供参考时明确使用通用风格，不声称已经模仿用户。原话、用户回顾、历史 AI 解释与新增创作分开；不能把 AI 的建议写成用户已经实现的进步，不添加真实经历、对话或第三方心理。

## 输出与迭代
保存到 creative-drafts/<批次>/，每次新建版本，不覆盖已有作品。写稿前识别可能暴露身份的细节，正文默认泛化姓名、地点和关系身份；审稿说明标明处理项。使用下述相应模板，审稿说明与正文分开。只生成本地草稿，不发布到社交平台或 GitHub，不因日记已获批准就认定公开创作已获批准。

用户改稿后比较版本，归纳具体偏好和反例到 private/style/ 中的平台档案，先作为待确认偏好，不从一次修改推断永久规则。已安装 lieflat-less-ai-tone 时可在最后读取其 SKILL.md 按规则清理；不可改用户逐字引用，缺少该 Skill 不阻断写作。不复制第三方文章段落或个人参考到公开仓库。
